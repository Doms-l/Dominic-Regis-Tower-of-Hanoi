## 📌 About the Project

Tower of Hanoi is an interactive puzzle game developed using SWI-Prolog as its backend and HTML, CSS, and Vanilla JavaScript for its frontend.

The objective is to move all disks from the first peg to the last peg while following the rules of the classic Tower of Hanoi puzzle.

This project demonstrates the application of recursion, logical programming, problem-solving, and web development.

## ✨ Features

- 🎮 Interactive Tower of Hanoi game
- 🧠 Prolog-based game logic
- 🤖 Automatic puzzle solver
- ⏱️ Game timer
- 🔢 Move counter
- ❌ Invalid move counter
- 🎨 Animated disk movements
- ⚡ Adjustable animation speed (1x–10x)
- 🏆 Victory notification
- 🟣 Gold, purple, and black user interface
- 🔇 Silent gameplay with no sound effects

## 🚀 How to Run the Project

### Requirements

- SWI-Prolog installed on your computer
- A modern web browser

### Installation

1. Download or clone this repository.
2. Open the project folder.
3. Open Command Prompt or PowerShell inside the folder.
4. Run the following command:

```bash
swipl hanoi.pl
```

5. Open your browser.
6. Visit:

```text
http://localhost:8080
```

## 📖 Rules of the Game

1. Move only one disk at a time.
2. Only the top disk of a peg can be moved.
3. A larger disk cannot be placed on a smaller disk.
4. Move all disks from Peg A to Peg C to win.
